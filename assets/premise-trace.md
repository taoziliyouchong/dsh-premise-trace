# 前提追溯 · 写法

> 本技能由 `dsh-premise-trace` 插件提供（bundled，唯一权威版本；改正文请编辑插件 `assets/premise-trace.md`）。

## 这个技能管什么

解释一个主体为什么从状态 A 转到状态 B，或判断它下一步转到哪；只有一个状态时，解释这个状态靠什么成立。

想起它的时刻：问「它为什么变成现在这样」「它什么时候会变」「它下一步会变成什么」「它靠什么撑着」；要判断一个方案、模式、组织、制度、技术、习惯、价格、共识、人物转变的走向。

先定问法（三档，共用同一套筛项）：

- **解释现状**——只有一个状态，问它靠什么成立：筛一张表，交一张表。
- **解释转变**——有 A、B 两个状态：筛两张表，交两段加转化原因。
- **判断走向**——在单态表或 B 表上逐条看条件异动，再落成两三个可能：交异动清单＋B（大概率）、C、D，每个后面跟一句「哪条条件一变就走到它」。

## 根本

一个状态靠几项成立条件撑着——撤掉任何一条就塌；条件变了，状态未必变；变了以后落到哪个状态，不止一种可能。

## 基本点（方向，不是判决表）

1. **必要**——撤了塌不塌：撤掉它状态还成立，它就是背景项（与状态无关的那类），不是条件。
2. **独立**——撤了剩下什么：剩下另一种可描述的状态，才是独立条件；剩下「这个状态不存在」是状态定义的一部分；剩下「世界没了」是背景项。后两类不单列。
3. **关键**——塌了有没有第二条路补位：有路可重建的是非关键成立条件（冷备），没有的是关键成立条件。关键可以多项，也可以为零：各项都有冷备就是组合失效，写组合，不挑一项；不拿「现在卡在哪一根」顶替——那是瓶颈，天然只有一条。
4. **级联**——撤掉会连带让几项一起失效：塌多深看这条。

## 怎么想

1. **定状态**：先定一个能判的状态——主体＋性质＋档位。不定档，撤项测试没有判据——撤掉一项，是塌还是降一档，说不清。只有一个状态就到此为止；要解释转变，再定第二个状态，两态必须同一个主体、同一套比较方面。先看 B 是怎么来的——自己的条件凑够才在，还是 A 的条件失效、无补位、剩下这个形态；后一种不去找 B 的成立条件，先看 A 哪几条失效、为什么没补位，再看为什么剩下的是这个形态。观察顺序是先看到状态变、再反推条件变；因果只有一条：条件变 → 状态变。

   - 状态段是让人判「这是哪个态」，不是论证这个态。性质变了是换状态；性质没变、只是强弱变了，才是升降一档。

2. **列候选**：先分题面与答法——题面＝这道题在问什么、为什么要问、问给谁听；答法＝谁来判、拿什么判、判出来的「我」是谁。再按「这道题要答出来，需要哪几样东西」把两边的功能列全：判定标准、待判的内容、判断的材料、要答案的动机、承当判断的「我」、能回应的关系、可用的行动。宁可多列，热备也先留着，筛的时候再剔。

   - 两态时只按「两态差在哪」挑，题面会整块消失，两态都在的项在候选阶段就被排除，后面补不回来。
   - 单态时按「这个状态要成立需要哪几样」列，不按「现在缺什么」列——按缺什么列会把候选压成待办清单，撑住状态的项反而漏掉。
   - 清单外的项，这套方法生产不出来：递归只沿关键项钻，交换只查两表不对称，两边都漏的补不回；要补只能换一种切法重列候选，或拿外部清单对照。

3. **筛项**：对每一项，在已定的每个状态各撤一次（只有一个状态就只撤它）；两态时两撤同时给出三个结果，不用分两遍走。三档按依赖顺序判，后一档的输入都是前一档的输出：

   - 一档·必要：撤了不塌 → 与状态无关，不是条件（背景项，或热备：撤了瞬间顶上、状态不中断），不单列。
   - 二档·独立：塌了，看剩下什么——剩下「这个状态不存在」→ 定义项，不单列；剩下「世界没了」→ 背景项，不单列；剩下另一种可描述状态 → 成立条件。
   - 三档·补位：成立条件，撤掉它有没有第二条路——有＝冷备，没有＝关键。

   不先撤判不了塌不塌，不先判成条件判不了冷热备，不先塌判不了关键。逐项定完再写，不挑一条就收。

4. **分内外**：内＝主体自身的结构，外＝环境给的。外部最容易漏——它一直在，就不觉得是条件。

5. **递归**：把每一条成立条件都当成一个新状态，重跑 1-4 步。拆出来的条件替换被拆的那条：被拆开的条件不再单列，表里写拆出来的；拆不出成立条件的，原项保留。同样过必要、独立、补位、内外四道筛；热备踢出；同一项在多处出现就合并；推到它不再起作用为止。

   - 递归只沿成立条件往下钻，补不回候选阶段漏掉的项；切法决定它看得见什么——把条件切成「判据在谁手里」，拆出来的是判据源；切成「他为什么需要判据」，才拆得到藏在里面的那条。

6. **交换**：两表互换，两个方向各跑一遍，只用来查漏——对方有、自己没有的项，回去过必要与独立两道判定，撤掉自己就塌才补。单态没有第二张表，跳过此步。

   - 每项按自己一侧的实测填，判定结果不继承：对方表里是关键，自己这边可能只是冷备，甚至撤了不塌、根本不补。
   - 补入后按本状态补关键判定（有第二路＝冷备，没有＝关键）；补入的项按递归规则当新状态重跑，推到它不再起作用。
   - 回炉递归若又长出新的项，再拿去对方表交换；交换再补、补再回炉，跑到两表都不再增项为止。
   - 交换只查两表不对称的项，两边都漏的项查不出来。

7. **读变化**：哪项先变、变成什么——失效、被替换、减弱、增强；状态跟不跟着变。硬规则：失效且无替代，状态必不成立；变弱或变强，状态可以不动。

顺序不能跳：必要 → 独立 → 补位 → 内外 → 递归 → 交换 → 补项回炉（关键判定＋递归）→ 读变化；回炉出新项就再交换，直到两表不再增项。单态跑到递归、读变化为止，跳过交换那一段。

## 筛出来的项怎么归

| 类 | 判定 | 写法 |
|---|---|---|
| 成立条件 | 撤了塌，且剩下的是另一种可描述的状态 | 单列，一行一项 |
| 关键成立条件 | 成立条件里，塌后没有第二条路补位 | 单列，标「关键」 |
| 非关键成立条件（冷备） | 有第二条路，但先塌后重建 | 单列 |
| 定义项 | 撤掉后「这个状态不存在」——状态语义自带的 | 不单列 |
| 背景项／热备 | 撤掉后「世界没了」，或撤掉后状态照旧成立；热备撤了瞬间顶上、状态不中断 | 不单列 |
| 维持项 | 撤了短期不塌、长期走弱 | 不进成立条件表，交付时单独标一句 |

- 发现漏项的信号：某条条件要预设另一条才说得通，被预设的那条就是漏项，补进来。
- 同一项经不同路径出现时并成一条，不重复计。

## 交付

按问法交：

- **解释现状（单态）**：一张成立条件表，表后一句「哪项现在在变、往哪变」。表外另标一句维持项——撤了短期不塌、长期走弱的那种：它不进成立条件表，但决定状态能撑多久。
- **解释转变（两态）**：三段——1. A 的成立条件表；2. B 的成立条件表；3. A→B 转化的原因和过程（单列，排最后；前两段只列成立条件，原因不写进表）。
- **判断走向**：异动清单＋两三个可能。清单一行一项（这项现在什么状态、异动长什么样、冷备能不能顶上）；可能写 B（大概率，附一句凭什么最大）、C、D，每个跟一句「哪条条件怎么变才走到它」。B 只有一个，另外至少列一条。

- 只列结论项：撤项测试没通过的不出现；一行一项；删掉某行后结论不变，那行就是过程，删。
- 成立条件表逐条标关键判定：关键项标「关键」，非关键项注明理由（有冷备、或被另一条路重建）；关键可以不止一项，有几项标几项；「现在谁在卡着」不作关键理由。
- 不写没通过筛项的候选，不写层级编号；默认一屏内，超了先合并同类项。
- 成立条件、原因、方向、快慢直接写，不用比方。

## 要预测时

拿最近的一张表（单态的现状表，或两态的 B 表）逐条盯：

1. 这项现在什么状态：成立、在变弱、在变强、已有替代。
2. 异动长什么样：失效、被替换、减弱、增强各是什么迹象。
3. 由条件怎么变推可能，不是只推一个：把「哪几项条件怎么变」的组合列出来，每组落到一个可能——
   B 是大概率，另有 C、D。不编：走得通的组合才写，走不通的不写。
4. 每个可能写三样：触发（哪几条条件怎么变）、长什么样（主体＋性质＋档位，能判是哪个状态）、
   大还是小（按条件现在离失效多远、补位顶不顶得上排，不硬给百分比）。
5. B 要写明凭什么最大：哪条条件离失效最近、哪条补位最薄；说不出，B 就不是大概率。
6. 非关键项失效：冷备顶上要多久；顶不上就按关键项算。
7. 变弱或变强，状态可以不动——不写成已翻。

维持项不在成立条件表里，但预测要带上：它决定状态能撑多久。

## 边界

- 对象：靠成立条件成立的状态或状态转变——组织、制度、技术、习惯、模式、价格、共识、人物转变；数学对象与物理常数没有前提。
- 两态要可比：同一个主体、同一套比较方面；同一状态的来回波动不算转变。单态没有可比对象，但「同一套比较方面」仍要守住，否则撤项测试没有判据。
- 单态只筛一张表，不硬凑 A、B 两态；它答的是靠什么成立，不答怎么补——补法另找一套。
- 维持项不进成立条件表：它不是条件，是状态能撑多久的来源。
- 成立条件与原因分层：成立条件是状态成立所靠的几项；原因是推着成立条件变的东西。两层不混。
- 看的是成立条件：缺了它这个状态不成立的那几项，不是它此刻需要外面有什么。
- 关键成立条件相对于状态与时间：同一主体的不同状态，关键项可以不同；同一个项今天可替换、明天可能没第二条路，判关键要按当时算。
- 剩余形态：A 的条件失效后剩下的形态会自己稳定、长出条件；之后按成立条件分析它，但别把后来长出的条件当成它出现的原因。
- 内外不是固定的：同一项可以从内变外。
- 力度：条件在变弱就写变弱，写明多快；没发生的不写成已发生。
- 分工：追「谁干的」用逆向倒推；讲否定之后的形态变化用扬弃；这里看成立条件怎么变、主体怎么换状态。
